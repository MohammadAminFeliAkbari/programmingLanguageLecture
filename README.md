# ارائهٔ تعاملی TypeScript

ارائهٔ آموزشی ۲۰ اسلایدی دربارهٔ مبانی TypeScript با رابط فارسی و راست‌چین.

## اجرا

```sh
npm install
npm run dev
```

برای ساخت نسخهٔ انتشار:

```sh
npm run build
npm run preview
```

## کنترل‌ها

- `ArrowRight` و `PageDown`: اسلاید بعدی
- `ArrowLeft` و `PageUp`: اسلاید قبلی
- `Home` و `End`: ابتدا و انتهای ارائه
- دکمهٔ شبکه: نمای کلی اسلایدها
- دکمهٔ نمایش: حالت ارائه
- دکمهٔ تمام‌صفحه: Fullscreen API
